# Чл. 4.
Застрахователите по чл. 3, ал. 1 предоставят в Информационния център справки за сключените и прекратените застрахователни договори по задължителните застраховки "Гражданска отговорност" и "Злополука". Справки по задължителна застраховка "Злополука" не се представят само когато лицензът по този вид застраховка е бил издаден за част от рисковете по нея и изключва рисковете по задължителната застраховка "Злополука".
