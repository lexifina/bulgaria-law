# Чл. 71.
(1) В случаите по чл. 68, ал. 2, чл. 70, ал. 1 и 3 звеното по управление на човешките ресурси запознава служителя с подходящите незаети длъжности, определени след преценката на органа по назначаването, за което се съставя протокол.
(2) Отказът на служителя да подпише протокола се удостоверява с подписите на двама други служители.
