# Наказателно-процесуален кодекс

Consolidated text of the Наказателно-процесуален кодекс as published by Министерство на правосъдието (mjs.bg): https://mjs.bg/home/normdoc/2135512224

This commit replaces the code's text as enacted (ДВ, бр. 86 от 28 октомври 2005 г., в сила от 29 април 2006 г.) with its current consolidated text. The amending acts between the two are not each built here; `git log` on this folder shows the ones that are.

The text includes the host's notes on each change ("(Изм. - ДВ, бр. ...)") as published there. It is the text after the newest amendment it names, ДВ бр. 59 от 2026 г.
