# Чл. 89.
(1) Когато комисията е образувала производство по своя инициатива в случаите по чл. 78, ал. 3, тя може да реши:
1. че не е налице нарушение на задължението по чл. 24;
2. да наложи имуществена санкция за неизпълнение на задължението по чл. 24, както и съответните мерки по чл. 90.
(2) Проучването по ал. 1 се извършва по реда на глава осма, както и по чл. 74 и 76.
