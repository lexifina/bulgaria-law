# Чл. 23.
(1) Проверките на място не са задължително условие за издаване на удостоверение за одобрение на лицата, които търгуват по смисъла на чл. 15, ал. 2, т. 1, без да задържат фуражи.
(2) Удостоверението за одобрение се издава на лицата по ал. 1 въз основа на представена декларация по образец за съответствие с изискванията на наредбата по чл. 5, ал. 2.
