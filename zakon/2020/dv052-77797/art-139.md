# Чл. 139.
Наказателните постановления по този закон и по подзаконовите нормативни актове по прилагането му се издават от:
1. директорите на областните дирекции по безопасност на храните - за нарушения, установени от лицата по чл. 138, ал. 1, т. 1;
2. директорите на регионалните здравни инспекции - за нарушения, установени от лицата по чл. 138, ал. 1, т. 2;
3. министъра на земеделието, храните и горите - за нарушения, установени от лицата по чл. 138, ал. 1, т. 3;
4. министъра на здравеопазването - за нарушения, установени от лицата по чл. 138, ал. 1, т. 4.
