# Чл. 31.
Производството по несъстоятелност може да се открие по молба на длъжник, който:
1. е физическо лице по чл. 2;
2. е неплатежоспособен;
3. е добросъвестен и по отношение на когото не са налице основания за недобросъвестност по чл. 9, ал. 2;
4. не е подавал молба за откриване на производство по несъстоятелност по реда на този закон, приключило с влязло в сила съдебно решение или прекратено поради установяване на недобросъвестност на длъжника.
