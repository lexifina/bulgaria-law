# Чл. 47.
(1) Лицата, пускащи на пазара продукти, след употребата на които се образуват масово разпространени отпадъци, за които се водят публични регистри по чл. 45, ал. 1, се регистрират при условия и по ред, определени в съответните наредби по чл. 13, ал. 1 и наредбата по чл. 59.
(2) Лицата, които притежават документ по чл. 35, могат да извършват и дейности като търговец и брокер по смисъла на този закон с отпадъците, посочени в документа, без регистрация по чл. 104.
