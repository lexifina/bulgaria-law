# Чл. 4.
(1) Държавната парична награда за особени заслуги по чл. 3, ал. 1, т. 1 и 2 се отпуска с решение на Народното събрание по предложение на Министерския съвет.
(2) Държавната парична награда за особени заслуги по чл. 3, ал. 1, т. 3 и конкретният й размер се отпускат с решение на Министерския съвет по предложение на министър-председателя.
