# Чл. 22.
След реализиране на плащането на събраните в производство по несъстоятелност суми по чл. 21 дирекция "Търговска несъстоятелност" при ЦУ на НАП в 7-дневен срок предоставя на МОСВ следната информация:
1. по кои актове за установени публични вземания е извършено плащането;
2. размер на погасените главници, лихви и разноски;
3. дата, на която сумите са постъпили по сметката на НАП;
4. основание за реализираното плащане.
