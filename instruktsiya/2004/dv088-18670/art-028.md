# Чл. 28.
(1) За отчетност на дейността по съпровождане на малолетни и непълнолетни лица в структурните звена се изготвят, водят и съхраняват:
1. заповед по чл. 15;
2. протокол по чл. 17;
3. опис по чл. 24, ал. 2;
4. разписка по чл. 24, ал. 2;
5. дневник по чл. 26.
(2) Екземпляр от протокола, описа и разписката по ал. 1 се прилагат към заповедта по чл. 15.
