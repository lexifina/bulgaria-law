# Bulgarian law in charts

[Български](README.md)

Charts on every country's law, from the whole of global-law: [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). The charts on Bulgaria alone will go here.

This folder is a placeholder: there are no charts yet. They will be drawn only from the data in this repository, as in [serbia-law's visualisations/](https://github.com/lexifina/serbia-law/tree/main/visualisations): one HTML page with all its data inside, still images for the READMEs, and the scripts that make them.

The charts will be descriptive: they will show what the sources record, not why.
