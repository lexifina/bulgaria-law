# Българското право в графики

[English](README.en.md)

Графики за правото на всички страни, от целия global-law: [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). Тук ще бъдат графиките само за България.

Засега тази папка само запазва мястото им: графики още няма. Те ще бъдат начертани само от данните в това хранилище, както във [visualisations/ на serbia-law](https://github.com/lexifina/serbia-law/tree/main/visualisations): една HTML страница с всички данни в нея, неподвижни изображения за README файловете и скриптовете, които ги създават.

Графиките ще бъдат описателни: ще показват какво записват източниците, а не защо.
