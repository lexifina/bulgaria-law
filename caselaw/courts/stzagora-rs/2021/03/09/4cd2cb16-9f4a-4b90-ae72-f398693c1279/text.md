С определение от 30.01.2020г. по НОХД 3267/2019г. по описа на Районен съд Стара Загора е одобрено споразумение за решаване на делото, по силата на което Б.В.М. е признат за виновен по повдигнатото му обвинение за извършено престъпление по чл. 195, ал.1, т.7, вр. с чл.194, ал.1, вр. чл.28, ал.1 НК, вр. чл.55, ал.1, т.1 НК.

Съгласно чл. 189, ал. 3 НПК, когато подсъдимият бъде признат за виновен, съдът го осъжда да заплати разноските по делото, включително адвокатското възнаграждение и другите разноски за служебно назначения защитник.

Ето защо, осъденото лице Б.В.М. следва да заплати по сметка на Националното бюро за правна помощ, гр. София определеното адвокатско възнаграждение за назначения му служебен защитник по ДП № 268/2018г. по описа на Второ РУ - Стара Загора и по НОХД № 3267/2019г. по описа на Районен съд – Стара Загора.
