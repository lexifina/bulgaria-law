# Чл. 4.
(1). За одобряване типа на МПС по отношение на максималната конструктивна скорост и на типа двигател по отношение на максималния въртящ момент и максималната мощност нето производителят подава заявление до изпълнителния директор на Изпълнителна агенция "Автомобилна администрация" (ИА "АА") в съответствие с глава втора, раздел I от Наредба № 117 от 2005 г. за одобряване типа на нови дву- и триколесни моторни превозни средства.
(2) Към заявлението по ал. 1 производителят прилага попълнен списък с данни в три екземпляра по образец с приложено към него съдържание, както следва:
1. съгласно приложение № 1 - при одобряване типа на МПС по отношение на максималната конструктивна скорост на двигателя;
2. съгласно приложение № 2 - при одобряване типа на двигател с принудително запалване по отношение на максималния въртящ момент и максималната мощност нето за мотопеди;
3. съгласно приложение № 3 - при одобряване типа на двигател с принудително запалване по отношение на максималния въртящ момент и максималната мощност нето за мотоциклети;
4. съгласно приложение № 4 - при одобряване типа на двигател със запалване чрез сгъстяване по отношение на максималния въртящ момент и максималната мощност нето за МПС.
