# Чл. 4.
(1) Към заявлението по чл. 3 производителят прилага попълнен списък с данни в 3 екземпляра по образец съгласно приложение №1 с приложено към него съдържание. Снимките, ако има такива, показват ПС от категория М1 с ясно различими подробности.
(2) Към заявлението по чл. 3 производителят прилага и:
1. ръководство за употреба;
2. протокол за проведени изпитвания от техническа служба;
3. документ за платена държавна такса.
