# § 10.
Приложение № 3 към чл. 14, ал. 1, т. 2 се изменя така:
"Приложение № 3 към чл. 14, ал. 1, т. 2
Списък на професионалните направления за институциите по чл. 14, ал. 1, т. 2
1. Растениевъдство
2. Растителна защита
3. Животновъдство
4. Ветеринарна медицина
5. Горско стопанство
6. Науки за земята
7. Икономика."
