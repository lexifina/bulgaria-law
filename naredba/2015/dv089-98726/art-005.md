# Чл. 5.
Земеделските стопани могат да кандидатстват и да получат извънредно подпомагане едновременно по схемата за подпомагане на база доставки и/или директни продажби на краве мляко през квотния период 2014/2015 г. по чл. 3 и по схемата за подпомагане на брой млечни крави в стопанството по чл. 4.
