# Чл. 19.
(1) На лицата, определени да участват в операции, мисии, занятия, учения, тренировки и лагери извън територията на страната, за времето на провеждане на непосредствената им подготовка се осигурява безплатна храна по приложение № 2, като на правоимащите по чл. 11, ал. 1, т. 3 и 4 се осигурява безплатна храна по приложение № 3, съответно по приложение № 4.
(2) На лицата по ал. 1 се осигуряват и добавка за утежнен енергоразход по приложение № 7, както и добавка минерална/трапезна вода по т. 2, буква "в" от приложение № 13.
