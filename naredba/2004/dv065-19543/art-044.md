# Чл. 44.
Инвестиционният посредник поддържа отчетност за всеки клиент със сметка за къси продажби, която съдържа най-малко данни за:
1. текущата (дневна) пазарна стойност на ценните книжа, предмет на къса продажба;
2. излишъка при къси продажби по чл. 37, ал. 2, съответно недостига при къси продажби по чл. 38;
3. броя и пазарната стойност на ценните книжа, предмет на къси продажби, чийто сетълмент не е извършен;
4. покупателната способност на клиента съгласно чл. 25, ал. 2.
