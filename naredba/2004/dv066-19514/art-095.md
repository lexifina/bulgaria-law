# Чл. 95.
Началникът на ТДУ, а при негово отсъствие - началникът на отдел "Оперативно-диспечерски", разрешава заявките за:
1. работа по електропроизводствени мощности до 5 MW, присъединени към преносната система;
2. работа по електропроизводствени мощности, независимо от мрежата на присъединяването им, определящи режима на ползване на вода от комплексните язовири;
3. работа по електропроводи и шинни системи с напрежение 110 kV освен в случаите по чл. 91, т. 2 и чл. 92 т. 3 и 4;
4. работа по силови трансформатори 110/средно напрежение;
5. работа по електропроводи от разпределителната мрежа, осигуряващи резервно захранване за собствени нужди на електрически централи и системни подстанции, освен в случаите по чл. 91, т. 4;
6. работа по средства на АСДУ втора група;
7. работа по релейната защита и автоматиката с напрежение до 110 kV включително.
