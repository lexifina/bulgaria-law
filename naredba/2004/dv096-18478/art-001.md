# Чл. 1.
С тази наредба се определят допълнителни правила за тарифно класиране на стоките в съответствие със:
1. обяснителните бележки към Хармонизираната система за описание и кодиране на стоките съгласно приложение № 1;
2. обяснителните бележки към Комбинираната номенклатура, прилагана в страните - членки на Европейския съюз, съгласно приложение № 2;
3. мненията за класиране на стоките, приети от Комитета по хармонизираната система на Световната митническа организация, съгласно приложение № 3;
4. решенията за класиране на стоките, прилагани в страните - членки на Европейския съюз, съгласно приложение № 4.
