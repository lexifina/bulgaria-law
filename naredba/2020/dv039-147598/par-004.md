# § 4.
Член 21 се изменя така:
"Чл. 21. (1) Съдържанието на учебника по майчин език, по религия и по хореография трябва да отговаря напълно на съответната учебна програма по отношение на учебното съдържание (теми, компетентности като очаквани резултати от обучението по съответните теми, нови понятия).
(2) Съдържанието на учебника по майчин език, по религия и по хореография не трябва да надвишава съответната учебна програма по отношение на учебното съдържание (теми, компетентности като очаквани резултати от обучението по съответните теми, нови понятия)."
