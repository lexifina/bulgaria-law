# § 2.
По смисъла на тази наредба:
1. "Биоциди" са биоцидите по Закона за защита от вредното въздействие на химичните вещества и препарати.
2. "Козметични продукти" са козметичните продукти по Закона за здравето.
3. "Медицински изделия" са медицинските изделия по Закона за медицинските изделия.
4. "Медицински специалисти" са медицинските специалисти по Закона за лекарствените продукти в хуманната медицина.
5. "Хранителни добавки" са хранителните добавки по Закона за храните.
6. "Храни със специално предназначение" са храните със специално предназначение по Закона за храните.
