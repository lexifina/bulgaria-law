# Чл. 2.
Държавният образователен стандарт за придобиването на квалификация по професията 815040 "Инструктор" съгласно приложението към тази наредба определя изискванията за придобиването на четвърта степен на професионална квалификация за специалностите 8150401 "Инструкторска дейност по фризьорски услуги", 8150402 "Инструкторска дейност по козметични услуги" и 8150403 "Инструкторска дейност по маникюр и педикюр".
