# Чл. 57.
(1) Документите по чл. 49 се съгласуват по електронен път между органите по чл. 48, ал. 2 по реда и в сроковете съгласно приложение № 16.
(2) Сертифициращият орган извършва преглед за съответствие на данните в окончателните документи по чл. 49.
(3) Документите по чл. 49, т. 1 - 3 се изпращат от сертифициращия орган на Европейската комисия чрез системата SFC 2014 в срока по чл. 59, параграф 5 от Регламент (ЕС, Евратом) № 966/2012.
