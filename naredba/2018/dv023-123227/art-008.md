# Чл. 8.
По преценка на психиатъра за нуждите на военномедицинската експертиза се извършва специализирано психологично изследване по методика, посочена в приложение № 14. При определяне годността за летателна длъжност на освидетелстваните се извършва специализирано авиопсихологично изследване по методиката, посочена в приложение № 18.
