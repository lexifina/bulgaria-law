# Чл. 2.
Производството пред Държавната комисия за енергийно и водно регулиране, наричана по-нататък "комисията" или "ДКЕВР", се открива:
1. по писмено заявление в случаите по чл. 1, ал. 1, т. 1, 3, 4, 5, 6, 10, 11 и по чл. 13, ал. 5 и 6;
2. по жалба или по искане за доброволно уреждане на спор по чл. 22 ЗЕ;
3. по инициатива на комисията в случаите по чл. 8;
4. по мотивирано искане на Европейската комисия по чл. 81а, ал. 2 ЗЕ.
