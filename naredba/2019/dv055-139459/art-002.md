# Чл. 2.
Искане за вписване на застрахователен брокер по електронна поща се подава по образец приложение № 1.1 (за заявителите юридически лица), съответно приложение № 1.2 (за заявителите еднолични търговци) към тази наредба. Искането може да се подаде и на интернет страницата на Комисията за финансов надзор чрез попълване на публикуван формуляр.
