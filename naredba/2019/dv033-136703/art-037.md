# Чл. 37.
(1) За съществуващи сгради в райони с ниска потенциална вероятност от проникване на радон се прилагат превантивни мерки по желание на възложителя. В този случай по преценка на проектанта се прилагат мерките по чл. 38, 39 и 40, като за всеки конкретен случай се отчитат по значимост показателите по чл. 32, ал. 1, т. 2.
(2) За съществуващи сгради в райони с умерена потенциална вероятност от проникване на радон се прилагат превантивни мерки. Техническите решения включват комбинация от мерки по чл. 38, 39 и 40 по преценка на проектанта, като за всеки конкретен случай се отчитат по значимост показателите по чл. 32, ал. 1, т. 2.
