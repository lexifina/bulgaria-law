# § 26.
Навсякъде в наредбата думите "учител по спортна подготовка", "учителя по спортна подготовка", "учители по спортна подготовка" и "учителите по спортна подготовка" се заменят съответно с "учител по специализирана подготовка", "учителя по специализирана подготовка", "учители по специализирана подготовка" и "учителите по специализирана подготовка".
