# Чл. 26.
Заявлението по чл. 23, ал. 1 се регистрира с индивидуален пореден входящ номер в ЦУ на НЗОК, по който заявителят може да следи движението му на интернет страницата на НЗОК. В случаите по чл. 23, ал. 3, предложение второ съответната РЗОК задължително уведомява заявителя за поредния входящ номер на заявлението в ЦУ на НЗОК по реда на чл. 12.
