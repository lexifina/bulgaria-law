# Чл. 1.
(1) С тази наредба се определят:
1. общите мерки за профилактика, ограничаване и ликвидиране на:
а) чума по говедата;
б) чума по дребните преживни животни;
в) епизоотична хеморагична болест по елените;
г) везикулозен стоматит по говедата, конете и свинете;
д) заразен нодуларен дерматит по говедата;
е) треска на долината Рифт;
ж) везикулозна болест по свинете;
з) шарка по овцете и козите;
и) африканска чума по свинете;
й) син език;
2. специфичните мерки срещу везикулозната болест по свинете;
3. методите за диагностика на болестите по т. 1;
4. задълженията на официалните ветеринарномедицински органи, физическите и юридическите лица за прилагане на мерките по т. 1 и 2;
5. условията и редът за прилагане на мерките по т. 1.
(2) Националната ветеринарномедицинска служба оказва съдействие на експертите от Европейската комисия при извършването на проверки относно прилагането на тази наредба.
