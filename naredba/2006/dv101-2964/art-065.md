# Чл. 65.
Въздушният превозвач - кандидат за достъп до пазара по наземно самообслужване за конкретната дейност, подава в ГД "ГВА" заявление, придружено от:
1. декларация за обстоятелствата по чл. 48ж, ал. 8 ЗГВ;
2. лиценз за оператор по наземно обслужване със заверка "самообслужване";
3. предварителен договор между наетия оператор по наземно обслужване и обслужвания авиационен оператор, ако ще осъществява самообслужване чрез нает оператор;
4. организационен проект за дейността и взаимодействие с летищната администрация.
