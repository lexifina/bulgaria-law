# Чл. 23.
(1) Когато от заключителната оценка се установи, че обект на недвижимото културно наследство има качества на НКЦ, директорът на НИНКН прави предложение до министъра на културата за класификация, категория и режими за опазване във връзка с предоставянето на статут на НКЦ, изготвено по образец съгласно приложение № 4.
(2) Когато от заключителната оценка се установи, че деклариран обект не отговаря на критериите по чл. 21, ал. 2, директорът на НИНКН прави предложение до министъра на културата за прекратяване на временния режим за опазване, изготвено по образец съгласно приложение № 4.
