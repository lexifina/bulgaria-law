# Чл. 28.
(1) В срока за подаване на документи по конкурса кандидатът се явява пред компетентната експертно-лекарска комисия за удостоверяване годността му по медицински показатели за държавна служба в МВР.
(2) В същия срок експертно-лекарската комисия изпраща по служебен път до звеното "Човешки ресурси" по чл. 23, ал. 1, т. 5 медицинското свидетелство на кандидата.
