# Чл. 152.
(1) В общия случай на изчисляване на хидротехническите съоръжения проекцията Eikj на изчислителната сеизмична сила по направление j, приложена в точка "k", съответстваща на i-тата форма на собствените трептения и действаща върху елемент с тегло Qk, се определя по формулата:
Eikj = CRKcbihikjQk (14),
където:
R е коефициентът на реагиране съгласно табл. 3;
C - коефициентът на значимост на съоръженията съгласно табл. 2;
Kc - сеизмичният коефициент; определя се съгласно чл. 140, 141 и 142;
hikj - коефициентът на разпределение на изчислителното сеизмично въздействие, съответстващо на i-тата форма на собствените трептения на конструкцията в точка "k" по направление j; определя се по формула (6);
Qk - теглото на елемента на съоръжението, отнесено към точка "k" и включващо присъединената водна маса в съответствие с изискванията на чл. 154;
bi - динамичният коефициент, който се определя, както следва:
1. за почви групи А и В:
а) при Ti > 0,10 s - по формула (3);
б) при Ti < 0,10 s - по формулата:
bi = 1,5 + 10Ti < 2,50 (15);
2. за почви група С:
а) при Ti > 0,15 s - по формула (4);
б) при Ti < 0,15 s - по формулата:
bi = 1,5 + 6,67Ti < 2,50 (16);
3. за почви група D:
а) при Ti > 0,2 s - по формула (5);
б) при Ti І 0,2 s - по формулата:
bi = 1,5 + 5Ti < 2,50 (17).
(2) Коефициентът bi се умножава допълнително със следните коефициенти:
1. за земноскални съоръжения:
а) за площадки с Kc < 0,15 - с 0,7;
б) за площадки с Kc > 0,15 - с 0,65;
2. за бетонни и стоманобетонни водоподпорни съоръжения:
а) за площадки с Kc < 0,15 - с 1,0;
б) за площадки с Kc > 0,15 - с 0,8.
(3) Стойността на произведението на bi и допълнителните коефициенти се приема не по-малка от 0,8.
