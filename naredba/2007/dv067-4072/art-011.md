# Чл. 11.
(1) За неинтервенционално проучване на лекарствен продукт по чл. 145 ЗЛПХМ възложителят представя в Изпълнителната агенция по лекарствата и комисията по етика по чл. 103 ЗЛПХМ заявление по образец за провеждане на клинично изпитване.
(2) Към заявлението се прилагат документите по чл. 2, т. 1, 2, 4, 5, 6, 7, 8, чл. 3, 4, чл. 5, ал. 2, чл. 6, ал. 1, т. 1, 2 и 4, чл. 7, т. 1, 3, 4, 7 и 8.
