# Чл. 20.
(1) Маркерните VHF радиофарове се инсталират на места, където се изисква точно определяне на местоположението на ВС при полет по въздушното трасе.
(2) Маркерните VHF радиофарове се използват като помощно средство при снижение на ВС по правилата за полети по прибори при полет извън въздушното трасе.
