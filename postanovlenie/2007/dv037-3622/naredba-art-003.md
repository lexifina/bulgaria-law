# Чл. 3.
Искане пред Министерството на финансите за изплащане номиналната стойност на ЖКЗ, издадени по чл. 5, ал. 3 ЗОСОИ, могат да подават:
1. лицата по чл. 2, обезщетени до влизането в сила на наредбата по реда на чл. 5, ал. 3 ЗОСОИ;
2. лицата по чл. 2 - страна по неприключили съдебни производства по чл. 7 ЗВСОНИ или страна по неприключили административни производства по чл. 5, ал. 3 ЗОСОИ, след получаване на депозитарна разписка за регистриране на полученото от тях обезщетение в ЖКЗ.
