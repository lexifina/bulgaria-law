# Чл. 17.
(1) Площите с доказано замърсена почва, върху които се изпълняват проектите по чл. 15, се вписват в подраздела по чл. 4, ал. 2, т. 2, буква "б".
(2) Площите с доказано замърсена почва, спрямо които са проведени мерки за въздействие, се вписват в подраздела по чл. 4, ал. 2, т. 3, буква "а".
