# Чл. 4.
(1) Със сумата по чл. 1, ал. 3 да се увеличат разходите по "Политика в областта на отбранителните способности", бюджетна програма "Медицинско осигуряване", по бюджета на Министерството на отбраната за 2018 г.
(2) Със сумата по чл. 1, ал. 3 да се увеличат показателите по чл. 11, ал. 3 от Закона за държавния бюджет на Република България за 2018 г.
