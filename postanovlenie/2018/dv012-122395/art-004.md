# Чл. 4.
(1) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат разходите по бюджетна програма "Административно обслужване, медицинска и психологическа експертиза" по бюджета на Министерството на транспорта, информационните технологии и съобщенията за 2018 г.
(2) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат показателите по чл. 24, ал. 3 от Закона за държавния бюджет на Република България за 2018 г.
