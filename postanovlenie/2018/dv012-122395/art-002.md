# Чл. 2.
(1) Със сумата по чл. 1, ал. 1, т. 1 да се увеличат разходите по бюджетна програма "Администрация" по бюджета на Министерството на икономиката за 2018 г.
(2) Със сумата по чл. 1, ал. 1, т. 1 да се увеличат показателите по чл. 19, ал. 3 от Закона за държавния бюджет на Република България за 2018 г.
