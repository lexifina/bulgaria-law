# Чл. 3.
(1) Със сумата по чл. 1, ал. 1, т. 2 да се увеличат разходите по бюджетна програма "Администрация" по бюджета на Министерството на околната среда и водите за 2018 г.
(2) Със сумата по чл. 1, ал. 1, т. 2 да се увеличат показателите по чл. 18, ал. 3 от Закона за държавния бюджет на Република България за 2018 г.
