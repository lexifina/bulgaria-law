# Чл. 7.
(1) Със сумата по чл. 1, ал. 2, т. 5 да се увеличат разходите по "Политика в областта на отбранителните способности", бюджетна програма "Военно-патриотично възпитание и военно-почивно дело" по бюджета на Министерството на отбраната за 2014 г.
(2) Със сумата по чл. 1, ал. 2, т. 5 да се увеличат показателите по чл. 11, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
