# Чл. 2.
(1) Със сумата по чл. 1, ал. 2 да се увеличат разходите по политика "Отбранителни способности", бюджетна програма "Управление на човешките ресурси" по бюджета на Министерството на отбраната за 2014 г.
(2) Със сумата по чл. 1, ал. 2 да се увеличат показателите по чл. 11, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
