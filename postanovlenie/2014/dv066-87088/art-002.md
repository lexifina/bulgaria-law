# Чл. 2.
(1) Със сумата по чл. 1, ал. 1 да се увеличат разходите по политика в областта на земеделието и селските райони, бюджетна програма "Безопасност по хранителната верига" по бюджета на Министерството на земеделието и храните за 2014 г.
(2) Със сумата по чл. 1, ал. 1 да се увеличат показателите по чл. 21, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
