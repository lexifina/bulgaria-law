# Чл. 17.
(1) Органът по чл. 2 с решение одобрява промяната на упълномощен представител по партида в регистъра, ако установи, че са изпълнени изискванията на наредбата и на Регламент (ЕС) № 389/2013, в срок 5 работни дни от приключване на проверката по чл. 16, ал. 5.
(2) Органът по чл. 2 отказва с решение да одобри промяната на упълномощен представител по партида в регистъра в случаите по чл. 6, ал. 2 в срока по ал. 1.
