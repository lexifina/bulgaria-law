# Чл. 20.
(1) Органът по чл. 2 с решение актуализира информацията по партида в регистъра, ако установи, че са изпълнени изискванията на наредбата и на Регламент (ЕС) № 389/2013, в срок 15 работни дни от приключване на проверката по чл. 19, ал. 4.
(2) Органът по чл. 2 отказва с решение да актуализира информацията по партида в регистъра в случаите по чл. 6, ал. 2 в срока по ал. 1.
