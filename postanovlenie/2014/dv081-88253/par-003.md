# § 3.
Създава се чл. 23:
"Чл. 23. (1) Министър-председателят определя Национален координатор по киберсигурността, който ръководи изработването на Национална стратегия за киберсигурност, план за действие по киберсигурността и изпълнява други задачи, свързани с киберсигурността.
(2) Съветът по сигурността определя функциите и задачите на Националния координатор по киберсигурността.
(3) Националният координатор по киберсигурността може да участва в заседанията на Съвета по сигурността по решение на председателя на съвета."
