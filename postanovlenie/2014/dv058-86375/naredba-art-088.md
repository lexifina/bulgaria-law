# Чл. 88.
(1) Ползвателят по всяко време може да промени органа по чл. 79, т. 2, който осъществява техническия надзор на въжената линия, като регистрира въжената линия пред новоизбрано лице по чл. 79, т. 2 и му предостави досието по чл. 101.
(2) В случай на промяна по ал. 1 ползвателят отправя до органа по чл. 79, т. 2, който първоначално е регистрирал въжената линия, писмено искане за предоставяне на досието по чл. 101, което съхранява. Органът е длъжен да предостави досието в 7-дневен срок от получаване на искането.
