# Чл. 2.
(1) Със сумата по чл. 1, ал. 1 да се увеличат разходите по "Политика в областта на устойчивото развитие на туризма", бюджетна програма "Развитие на националната туристическа реклама" по бюджета на Министерството на икономиката и енергетиката за 2014 г.
(2) Със сумата по чл. 1, ал. 1 да се увеличат показателите по чл. 19, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
