# Чл. 4.
(1) Със сумата по чл. 1, ал. 2, т. 3 да се увеличат разходите по "Политика в областта на земеделието и селските райони", бюджетна програма "Образование" по бюджета на Министерството на земеделието и храните за 2014 г.
(2) Със сумата по чл. 1, ал. 2, т. 3 да се увеличат показателите по чл. 21, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
