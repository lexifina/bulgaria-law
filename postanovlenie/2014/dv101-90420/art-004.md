# Чл. 4.
(1) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат разходите по бюджета на Министерството на здравеопазването за 2014 г. по Политика в областта на диагностиката и лечението, бюджетна програма "Осигуряване на медицинска помощ на специфични групи от населението" - 24 200,0 хил. лв.
(2) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат показателите по чл. 15, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
