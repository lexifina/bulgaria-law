# Чл. 2.
Със сумата по чл. 1, ал. 1 да се увеличат разходите по бюджета на Министерството на правосъдието за 2014 г. по "Политика в областта на изпълнение на наказанията", разпределени, както следва:
1. по бюджетна програма "Затвори - изолация на правонарушители" - 7 600 000 лв.;
2. по бюджетна програма "Следствени арести и пробация" - 400 000 лв.
