# Чл. 4.
Със сумата по чл. 1, т. 2 да се увеличат разходите по бюджета на Министерския съвет за 2014 г. по Политика в областта на осъществяването на държавните функции на територията на областите в Република България, бюджетна програма "Осъществяване на държавната политика на областно ниво" и показателите по чл. 6, ал. 3 от Закона за държавния бюджет на Република България за 2014 г.
