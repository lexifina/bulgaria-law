# Чл. 2.
Със сумата по чл. 1, ал. 1 да се увеличат утвърдените разходи за персонал по бюджета на Министерството на земеделието и храните за 2024 г., както следва:
1. по "Политика в областта на земеделието и селските райони" - общо с 19 415 663 лв., в това число:
а) по бюджетна програма "Земеделски земи" - със 7 227 101 лв.;
б) по бюджетна програма "Природни ресурси в селските райони" - със 7000 лв.;
в) по бюджетна програма "Растениевъдство" - с 3 768 372 лв.;
г) по бюджетна програма "Хидромелиорации" - с 36 000 лв.;
д) по бюджетна програма "Животновъдство" - с 451 976 лв.;
е) по бюджетна програма "Организация на пазарите и държавни помощи" - със 158 000 лв.;
ж) по бюджетна програма "Агростатистика, анализи и прогнози" - със 77 000 лв.;
з) по бюджетна програма "Съвети и консултации" - със 190 943 лв.;
и) по бюджетна програма "Земеделска техника" - с 83 000 лв.;
й) по бюджетна програма "Безопасност по хранителната верига" - със 7 384 271 лв.;
к) по бюджетна програма "Подобряване на живота в селските райони" - с 32 000 лв.;
2. по "Политика в областта на рибарството и аквакултурите", бюджетна програма "Рибарство и аквакултури" - със 783 182 лв.;
3. по "Политика в областта на съхраняването и увеличаването на горите и дивеча", бюджетна програма "Специализирани дейности в горските територии" - с 2 845 219 лв.;
4. по бюджетна програма "Администрация" - със 703 930 лв.
