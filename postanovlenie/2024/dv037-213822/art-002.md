# Чл. 2.
Със сумата по чл. 1, ал. 1 да се увеличат разходите по области на политики и бюджетни програми, както следва:
1. по "Политика в областта на устойчивото икономическо развитие и конкурентоспособност" - със сумата 4 250 438 лв. по показател персонал, в т.ч.:
а) по бюджетна програма "Облекчаване на регулации, опростяване на процедури по предоставяне на административни услуги" - със сумата 209 520 лв.;
б) по бюджетна програма "Насърчаване на малките и средните предприятия и индустрията" - със сумата 74 693 лв.;
в) по бюджетна програма "Закрила на обектите на индустриална собственост" - със сумата 361 350 лв.;
г) по бюджетна програма "Инфраструктура по качеството в подкрепа развитието на икономиката" - със сумата 2 457 034 лв.;
д) по бюджетна програма "Подобряване на възможностите за участие в единния европейски пазар" - със сумата 95 349 лв.;
е) по бюджетна програма "Преструктуриране и ефективно управление на държавната собственост" - със сумата 256 690 лв.;
ж) по бюджетна програма "Защита на потребителите" - със сумата 795 802 лв.;
2. по "Политика в областта на ефективното външноикономическо сътрудничество" - със сумата 408 682 лв. по показател персонал, в т.ч. по бюджетна програма "Реализация на експортния потенциал и участие в търговската политика на Европейския съюз" - със сумата 408 682 лв.;
3. по бюджетна програма "Администрация", по показател персонал - със сумата 428 828 лв.
