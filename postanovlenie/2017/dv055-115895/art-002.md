# Чл. 2.
Средствата по чл. 1, т. 1 да се предоставят на общините чрез Агенцията за социално подпомагане въз основа на подписано двустранно споразумение за предоставяне на социалните услуги "Личен асистент", "Социален асистент" и "Домашен помощник" на потребителите, за които е извършена социална оценка по правилата на операция "Независим живот", финансирана по Оперативна програма "Развитие на човешките ресурси" 2014 - 2020 г., и след приключване на финансирането по програмата.
