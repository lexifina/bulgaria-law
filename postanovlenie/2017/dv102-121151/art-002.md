# Чл. 2.
Със сумата по чл. 1, ал. 1 да се увеличат:
1. разходите по "Политика в областта на земеделието и селските райони", бюджетна програма "Безопасност по хранителната верига", по бюджета на Министерството на земеделието, храните и горите за 2017 г.;
2. показателите по чл. 23, ал. 3 от Закона за държавния бюджет на Република България за 2017 г.
