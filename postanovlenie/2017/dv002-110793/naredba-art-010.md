# Чл. 10.
(1) Изпълнителна агенция "Главна инспекция по труда" поддържа единен национален уебсайт с българска и английска езикова версия, съдържащ актуална информация за:
1. условията на работа по чл. 9, ал. 1 и 4;
2. задълженията по чл. 11, ал. 1;
3. отговорността при веригите от подизпълнители съгласно чл. 357, ал. 4 КТ;
4. лицата за контакт, на които е възложено обработването на искания за предоставяне на информация;
5. условията на работа по разпрострените по реда на чл. 51б КТ колективни трудови договори.
(2) Информацията по ал. 1 се предоставя по начин, който е достъпен за хората с увреждания.
