# Чл. 57.
(1) Когато организацията по оползотворяване на ИУГ или лицата, които пускат на пазара гуми, които изпълняват задълженията си индивидуално, не представят в срок доклад по чл. 40, ал. 2, те се включват в заповедта по чл. 56.
(2) При установено несъответствие в информацията на първичните счетоводни документи по чл. 48, т. 3 с вътрешнофирмената спецификация и с месечната справка-декларация, представени на организацията по оползотворяване от нейните членове, членовете на организацията се включват в заповедта по чл. 56.
(3) При установено незаплащане от членовете на организацията по оползотворяване на уговореното възнаграждение към нея те се включват в заповедта по чл. 56.
