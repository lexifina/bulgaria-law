# Чл. 2.
Със сумата по чл. 1, ал. 1 да се увеличат разходите за персонал по бюджета на Министерството на икономиката, по "Политика в областта на устойчивото икономическо развитие и конкурентоспособност" с 1 195 000 лв., както следва:
1. по бюджетна програма "Облекчаване на регулации, опростяване на процедури по предоставяне на административни услуги" с 69 900 лв.;
2. по бюджетна програма "Инфраструктура по качеството в подкрепа развитието на икономиката" със 791 500 лв.;
3. по бюджетна програма "Защита на потребителите" с 333 600 лв.
