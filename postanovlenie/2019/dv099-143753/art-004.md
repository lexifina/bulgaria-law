# Чл. 4.
(1) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат разходите по бюджетна програма "Ефективна администрация и координация" по бюджета на Министерството на регионалното развитие и благоустройството за 2019 г.
(2) Със сумата по чл. 1, ал. 1, т. 3 да се увеличат показателите по чл. 22, ал. 3 от Закона за държавния бюджет на Република България за 2019 г.
