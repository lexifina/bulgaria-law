# Чл. 1.
Одобрява вътрешнокомпенсирани промени на утвърдените разходи по области на политики/бюджетни програми по бюджета на Министерството на правосъдието за 2019 г., както следва:
1. намалява утвърдените разходи за персонал по "Политика в областта на правосъдието" с 36 000 лв., по бюджетна програма "Регистри";
2. увеличава утвърдените разходи за персонал по бюджетна програма "Администрация" с 36 000 лв.
