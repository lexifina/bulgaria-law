# § 1.
По смисъла на тази наредба "Юридически лица с военновременни задачи по отбраната на страната" са търговски дружества по смисъла на Търговския закон, юридически лица, създадени по реда на Закона за кооперациите, държавни предприятия и други организации, създадени със закон, на които са възложени военновременни задачи по отбраната на страната.
