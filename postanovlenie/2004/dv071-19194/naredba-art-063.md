# Чл. 63.
При конструиране на оборудването се отчитат:
1. натоварванията, които възникват при манипулиране с максимален брой касети;
2. натоварванията при сеизмични въздействия;
3. натоварванията от хидростатичното налягане на водата;
4. натоварванията, които възникват под въздействието на промени на температурата;
5. едновременното действие на натоварванията по т. 1 - 4.
