# § 10.
В приложение № 2 към чл. 11, ал. 5 се правят следните изменения и допълнения:
1. В част I "Клиники и/или отделения с легла":
а) точка 1 се изменя така:
"1. І-ва Клиника по вътрешни болести с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по вътрешни болести:
1.1. отделение по нефрология и диализно лечение с ІІІ ниво на компетентност в съответствие с медицинския стандарт по нефрология и в съответствие с медицинския стандарт по диализно лечение;
1.2. отделение по ревматология с ІІ ниво на компетентност в съответствие с медицинския стандарт по ревматология;"
б) в т. 3 се създават подточки 3.1 и 3.2:
"3.1. отделение по кардиология с II ниво на компетентност в съответствие с утвърдения медицински стандарт по кардиология;
3.2. отделение по интензивно кардиологично лечение с II ниво на компетентност в съответствие с утвърдения медицински стандарт по кардиология;"
в) точки 6 - 9 се изменят така:
"6. Клиника по ушно-носно и гърлени болести с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по ушно-носно и гърлени болести;
7. ІІ-ра Клиника по вътрешни болести с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по вътрешни болести:
7.1. отделение по пневмология с ІІІ ниво на компетентност в съответствие с медицинския стандарт по пневмология и фтизиатрия;
7.2. отделение по клинична алергология с ІІІ ниво на компетентност в съответствие с медицинския стандарт по клинична алергология;
8. Клиника по нервни болести с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по нервни болести;
9. Клиника по ортопедия и травматология с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по ортопедия и травматология;"
г) в т. 10 думата "Отделение" се заменя с "Клиника";
д) в т. 11 след думите "Отделение по" се добавя "клинична";
е) точки 16 и 17 се изменят така:
"16. Клиника по урология с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по урология;
17. Отделение по спешна медицина с ІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по спешна медицина;"
ж) точка 19 се изменя така:
"19. Отделение по физикална и рехабилитационна медицина с ІІІ ниво на компетентност в съответствие с утвърдения медицински стандарт по физикална рехабилитационна медицина."
2. В част II "Клиники и/или отделения без легла" т. 3 се изменя така:
"3. Отделение по клинична патология в съответствие с утвърдения медицински стандарт по клинична патология."
