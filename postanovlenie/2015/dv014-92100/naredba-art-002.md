# Чл. 2.
При оценяване на съответствието на енергопотребяващите продукти по чл. 1, ал. 1 с изискванията за екопроектиране производителят може да избира между процедурите:
1. "Вътрешен проектен контрол" съгласно приложение № 1;
2. "Управленска система за оценяване на съответствие" съгласно приложение № 2.
