# Чл. 8.
(1) Лабораториите по чл. 3, ал. 2, включени в списъка по чл. 22, ал. 1, т. 8 ЗХ, уведомяват ДКХ за всички промени в обстоятелствата по чл. 5, като прилагат и актуални документи по чл. 6, ал. 2, удостоверяващи промяната.
(2) Когато лаборатория по чл. 3, ал. 2, включена в списъка по чл. 22, ал. 1, т. 8 ЗХ, престане да отговаря на изискванията по чл. 5, ДКХ заличава лабораторията от списъка по предложение на председателя на ДКХ.
