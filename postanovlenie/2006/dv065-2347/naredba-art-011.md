# Чл. 11.
(1) Съдържанието и форматът на информационните листове, които се изготвят за битовите уреди по чл. 2, ал. 1, трябва да са в съответствие с приложение № 4, както следва:
1. хладилни уреди - приложение № 4, част I;
2. перални машини - приложение № 4, част II;
3. барабанни сушилни машини - приложение № 4, част III;
4. комбинирани перални/сушилни машини - приложение № 4, част IV;
5. миялни машини - приложение № 4, част V;
6. лампи - приложение № 4, част VI;
7. въздушни климатизатори - приложение № 4, част VII;
8. електрически фурни - приложение № 4, част VIII.
(2) От датата на влизането в сила на Договора за присъединяване на Република България към Европейския съюз съдържанието и форматът на информационните листове, които се изготвят за битовите уреди по чл. 2, ал. 1, трябва да са в съответствие с приложение № 5, както следва:
1. хладилни уреди - приложение № 5, част I;
2. перални машини - приложение № 5, част II;
3. барабанни сушилни машини - приложение № 5, част III;
4. комбинирани перални/сушилни машини - приложение № 5, част IV;
5. миялни машини - приложение № 5, част V;
6. лампи - приложение № 5, част VI;
7. въздушни климатизатори - приложение № 5, част VII;
8. електрически фурни - приложение № 5, част VIII.
